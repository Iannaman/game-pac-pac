# PAC PAC 3.0.0 - Players vs Ghosts
Complete package based on 2.9.0. Adds Hunt role lobby, two runners, one to four player-controlled ghost slots, host-authoritative input validation, base balancing, multiplayer Pac-Man power reversal, respawn and dedicated tutorial. Historical Arcade, records, medals, editor, Level Engine and Dynamic Maze remain included.

The included build provides full local role testing and the authoritative Hunt simulation/API. The previous two-device WebRTC transport remains available for the existing Coop/Versus modes; a signaling/TURN deployment is still required for remote-device operation.
