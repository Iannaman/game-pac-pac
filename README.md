# PAC PAC 2.7.0 - Level Engine v2

Full GitHub package. Includes all 2.5.1 gameplay, 2.6.0 Mode Hub/tutorials and Level Engine v2.

- LegacyGeneratorV1 remains the original generator and keeps existing level numbering and save keys.
- Stable legacy IDs: `legacy-v1-000001`.
- Stable official IDs and revisions.
- Separate terrain, objects, actors, mechanisms and metadata layers.
- Defensive schema, size, tile, spawn and reachability validation.
- Three new official maps: Incroci Neon, Anelli di Luce and Doppio Percorso.
- Official maps are converted through an adapter to the current runtime. Dynamic mechanisms are reserved for 2.8.0.

No legacy level or stored record is deleted or renumbered.
